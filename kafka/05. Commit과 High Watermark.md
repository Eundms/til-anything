# commit

## 1. Consumer commit
- Consumer 가 consume하여 처리한 records의 마지막 offset에 1을 더한 값 (즉, 다음 차례의 offset을 커밋)
- 커밋된 offset의 직전까지 consumer에서 처리 완료되었음을 의미 
1) kafka cluster에서 offset 4까지의 레코드들을 consume
2) consumer group이 consume한 레코드들을 모두 처리 
3) consume한 레코드들의 마지막 offset의 다음 offset을 Group Coordinator에 commit (여기서는 offset 5)

## 2. Broker-side commit
- ISR(in-sync replica)에 속한 모든 replica에 레코드가 복제되면 leader replica는 해당 레코드를 커밋
  - 복제가 잘되었다! 
- 레코드를 커밋한다는 것은 `High Watermark`를 해당 레코드의 오프셋 다음까지 전진시키는 것을 의미 
- High Watermark(HW) : 믿고 consume 할 수 있도록 커밋된 레코드들의 offset의 상한 경계 (exclusive offset)
  - Leader와 Follower의 HW가 증가하는 데는 약간의 시간 차가 존재한다 
- Log End Effort(LEO) : 마지막으로 append된 레코드의 그 다음 offset

> consumer는 HW 이전의 레코드들만 읽어 간다
